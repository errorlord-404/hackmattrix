# Cutover preflight

Cutover consumes only the checksummed machine evidence generated by
`tests/reports/run_release_gates.py`. Markdown reports are informational and
cannot authorize traffic.

```powershell
python tests/reports/run_release_gates.py --profile ci --output tests/results/gate-results.json --checksums tests/results/artifact-checksums.json
python scripts/cutover.py --results tests/results/gate-results.json --checksums tests/results/artifact-checksums.json --dry-run --require-precutover --require-all
```

The command must fail closed when any gate is missing, stale, nonzero, or has a
checksum mismatch. This repository currently fails the preflight because the
CV release scope is intentionally not approved.
